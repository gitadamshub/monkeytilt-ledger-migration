Disconnect

An authorized administrator can disconnect the app in QuickBooks' connected-app settings. An authorized local operator can also run the connector's disconnect command with the exact company identifier and explicit confirmation.

The local command revokes the authorization and removes that company's tokens from macOS Keychain after Intuit accepts the revocation. It does not delete QuickBooks entries or local accounting evidence.

This informational page does not revoke access by itself. If you disconnect through QuickBooks, contact the internal operator to run forget --realm COMPANY_ID --confirm-realm COMPANY_ID with the approved configuration. This separately confirmed command removes the local token only. It does not request or prove remote revocation. If the local disconnect command reports a provider error, resolve that result or explicitly perform local cleanup; do not assume remote access has been revoked.
